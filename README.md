# Blender Quick Export Selection

Export selected objects with just one click.

## 解决了什么痛点

Blender's "Selected Only" export option isn't enabled by default. It's easy to forget to check it and accidentally export your entire 1 GB scene. This button solves that problem by opening Blender's native export window with "Selected Only" already enabled!

---

## Install

1. Download ...
2. Open the Add-ons preferences and choose "Install from Disk".
3. Enjoy!

---

## Tech Stack

Opens Blender's native export window with the selection-only option set to `True`.
